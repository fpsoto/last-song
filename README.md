# LAST SONG

> *A rockstar never dies. He just gets older.*

**[Play it in your browser](https://fpsoto.github.io/last-song/)**

A playable vertical slice of a 2D arcade beat 'em up, built with plain **HTML5, CSS3 and vanilla JavaScript (Canvas 2D)**. No frameworks, no build step, no backend, no external assets: every sprite, background and sound is generated by code.

You are **Jack Ryder**, a 38-year-old musician who never made it. Fight your way through **1984 – THE LAST BAR**, past roadies and groupies, and take down the first boss: **THE KING OF RIFFS**.

## Controls

| Action | Keyboard |
| --- | --- |
| Move (left / right / into the screen / towards the camera) | `A` `D` `W` `S` or arrow keys |
| Punch (fast; three hits in a row end in a knockdown) | `J` |
| Kick (slow, strong, knocks down) | `K` |
| Jump (press `J` or `K` in the air for a flying kick) | `Space` |
| The Last Solo (needs a full meter) | `L` |
| Start / confirm | `Enter` |
| Pause | `Esc` |
| Sound on / off | `M` (or the button in the top-right corner) |

On touch devices a virtual stick and PUNCH / KICK / START / PAUSE buttons appear automatically.

Tip: the boss' shockwave travels along one lane of the floor. Step up or down (`W` / `S`) or jump over it. The punk's charge can be dodged the same way.

## How it plays

- **Five zones, four waves, then the boss**: entrance, bar, game room, backstage hall and the stage. Each wave locks the screen until everyone is down; a "GO" arrow shows when you can move on.
- **Three regular enemies**: Roadie (slow, hits hard), Groupie (fast, fragile) and Punk (charges at you from a distance after a visible crouch). The last wave before the boss mixes all three in a staggered stream.
- **The Last Solo**: every KO fills the SOLO meter under your health bar. At 100% press `L` for a shockwave that damages and knocks down everything close to you, smashes scenery and cancels the boss' shockwaves. Using it empties the meter, and KOs caused by the solo itself don't refill it.
- **Breakables**: wooden crates, beer kegs, equipment cases and amps. Smash them for a burger (+35 HP), a beer (+15 HP and some solo) or a golden pick (+45 solo). Items vanish after a few seconds, and are not picked up when they wouldn't help.

## Run it locally

Double-click `index.html`. That's it: the game uses classic scripts (not ES modules), so it works straight from the file system.

If you prefer a local server, any static one works, for example `python -m http.server` and then open `http://localhost:8000`.

## Publish on GitHub Pages

The repository deploys itself with GitHub Actions (`.github/workflows/pages.yml`): every push to `main` checks the scripts and publishes the site.

To do the same in your own copy: push the folder to GitHub, then in **Settings → Pages → Build and deployment** choose **GitHub Actions** as the source. The game goes live at `https://<user>.github.io/<repository>/`.

All paths are relative, so it works under any repository name.

## Contributing

- Every change starts as an issue (Feature or Bug template) with a milestone.
- Work on a branch cut from `develop`, named `feature/<issue>-<slug>`, `bug/<issue>-<slug>` or `chore/<issue>-<slug>`, and open a PR into `develop` that starts with `Closes #<issue>`. Merging closes the issue automatically.
- Releases are branches: `release/X.Y.Z` is cut from `develop` and merged into `main`, which creates the tag, the GitHub Release and the Pages deploy.
- The details (labels, milestones, versioning) are in [CLAUDE.md](CLAUDE.md).

## Project structure

```
index.html        page, canvas, touch controls, script loading order
styles.css        arcade cabinet frame, CRT overlay, touch layout
js/
  core.js         namespace (LS), constants, helpers
  input.js        keyboard + touch -> abstract actions
  audio.js        Web Audio sound effects and music sequencer
  collision.js    spatial tests (attack reach, floor limits, props)
  camera.js       scrolling, wave locks, screen shake
  effects.js      hit sparks, dust, comic text, flashes
  hud.js          bitmap font + arcade HUD
  sprites.js      procedural pixel-art character rig and poses
  background.js   procedural stage art (scene registry)
  entity.js       Fighter base class (health, knockback, shared states)
  props.js        breakable scenery and the pickups it drops
  combat.js       attack resolution, independent from rendering
  player.js       Jack Ryder
  enemy.js        Roadie and Groupie (data-driven) + AI state machine
  boss.js         The King of Riffs (boss registry)
  levels.js       era registry: waves, boss, music, texts
  renderer.js     draws the world and every screen
  game.js         global state machine and level flow
  main.js         canvas scaling and game loop
```

### Adding a new decade

The game is organised around **eras** (`js/levels.js`). 1950, 1960 and 1970 are already registered as stubs. To make one playable:

1. Add a scene to `LS.Scenes` in `background.js` (`build`, `dynamic`, `foreground`, `prop`).
2. Add its enemy types to `LS.ENEMY_TYPES` in `enemy.js` and their look/poses in `sprites.js`.
3. Add its boss class to `LS.BOSSES` in `boss.js`.
4. Fill in the era entry in `levels.js` (palette, music patterns, waves, boss, texts) and set `available: true`.

## Development flags

Append these to the URL:

| Flag | Effect |
| --- | --- |
| `?debug=1` | Draws hit boxes, shows state in the page title, enables keys `1` / `2` (skip to wave 2 / boss) and `3` (boss at 10 HP) |
| `?start=1` | Skips the menus |
| `?skip=N` | Starts at wave N+1 (`N` = 1 to 3) or at the boss (`N` = 4); needs `start=1` |
| `?power=100` | Starts with a full solo meter |
| `?spawn=punk,roadie` | Puts those enemies next to Jack right away |
| `?seq=jump:2,kick:2.2` | Presses those actions when the game clock reaches the given seconds |
| `?god=1` | The player takes no damage |
| `?hp=N` | Starts with N health |
| `?auto=1` | A simple bot plays the level |
| `?warp=N` | Simulates N seconds instantly before the first frame |

## Scope and known limitations

This is a proof of concept with a single stage. Not included on purpose: inventory, skill trees, complex combos, saves, multiplayer, character select, shops or RPG progression.

- Music only starts once the level begins, after the first key press or tap (browsers block audio before a user gesture).
- Enemies and the boss share the same generic "hurt / knocked down" animations.
- No gamepad support yet.
